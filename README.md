### 🚀 Featured Projects

#### 🌴 [Apa Kabar Bali — Bilingual News Portal](https://apakabarbali.com)
A live news portal about Bali in **English and Bahasa Indonesia**, built and run as a personal project. *(Source is private.)*

- 🧱 **Symfony 7.4 LTS · PHP 8.5 · Twig** — stateless frontend, content served from a separate TMS via a cached, scoped HTTP client
- 🤖 **AI-supported editorial workflow** — custom agents assist with content and assets
- 🎨 **Tailwind CSS 4 + AssetMapper** — no Node build step, self-hosted fonts, custom Balinese batik design system
- 🔎 **SEO** — Google News sitemap, JSON-LD, localized titles & descriptions
- 🐳 **Docker** production deployment
