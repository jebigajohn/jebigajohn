### 🚀 Featured Projects

#### 🤖 [ReportCube — AI-Powered Claims Analysis Platform](https://reportcube.de)
A production **multi-tenant SaaS platform** for automated insurance claims analysis and report generation — built from scratch as Co-Founder since November 2024.

Key features:
- 🔍 **GPT-4o Vision** — AI damage image analysis with 2-phase parallel processing
- 📄 **LLM Report Generation** — automated PDF report generation server-side
- 🔐 **OIDC Auth** — Authorization Code + PKCE via custom OpenIddict identity provider
- 🏢 **Multi-tenancy** — isolated SQL Server database per tenant, JWT-based claim routing
- 🧪 **265+ tests** — Vitest unit tests + Playwright E2E + axe-core accessibility audits
- 🔒 **Security** — OWASP Top 10, GDPR-compliant, magic byte file validation, RFC 7807 error handling
- ⚙️ **AI Workflow Engineering** — custom Claude/Copilot agent system, spec-driven development, automated PR review pipeline

Tech Stack: React 19 · TypeScript · Zustand · TanStack Query · .NET 10 · EF Core · SQL Server · Tailwind CSS · GitHub Actions · Docker · IIS

#### 🔥 [Spark — Premium Car Rental Platform (Bootcamp Project)](https://morent-chi.vercel.app)
A rebrand and redesign of "Morent" into **Spark**: a premium, mobile‑first car rental prototype built in 2 weeks during the SuperCode bootcamp. Combines a polished UI, interactive maps and a data‑driven AI assistant ("Sparky") to streamline vehicle discovery and bookings.

Key features:
- 🤖 Sparky AI Chatbot — Google Gemini via Vercel AI SDK; rate limiting & local chat history
- 🗺️ Interactive Maps — MapLibre + OpenStreetMap
- 📅 Complete Booking System — end‑to‑end flow with validation
- ❤️ Favorites · 🌙 Dark/Light Mode · ⭐ Reviews & Ratings · 🔍 Advanced Filters
- ♿ Accessibility — ARIA, keyboard navigation · 🔎 SEO — meta tags, Open Graph, JSON‑LD

Tech Stack: React 19 · TypeScript · TanStack Router/Query · Tailwind CSS · shadcn/ui · Supabase · Google Gemini · Vite  
Team: 3 developers · 2 weeks · ~78 components · ~23.7k LOC
